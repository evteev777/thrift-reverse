# Проверка выпуска 1.1.0

Дата: 2026-10-15 (Europe/Moscow).

## Выполнено

- Python 3.12.14: 21/21 unit/integration tests прошли.
- Apache Thrift compiler 0.24.0 собран из официального релизного архива:
  `https://archive.apache.org/dist/thrift/0.24.0/thrift-0.24.0.tar.gz`.
- SHA-256 архива проверен:
  `e0fa5839a4c5c1d631b0931cf2c554ebbfa4e2fee3a9fb3ffd4f82ce4396c6e4`.
- Использовался Java backend; все исходники compiler — без изменений.
- Интеграционные фикстуры покрывают вложенные коллекции, binary, uuid, union,
  exception, void/oneway, наследование, межпакетные ссылки, defaults, объединение namespace.
- Негативные тесты: отсутствующие зависимости/метаданные/результаты методов,
  дубликаты Java-классов, неизвестные metadata, защита существующего output.
- `build-compiler.sh` прошёл `sh -n`; команды C++-сборки проверены напрямую.
- `compose.yaml` разобран YAML-парсером; проверены имена сервисов.

- Генерация Java: рекурсивный каталог и один IDL с include, дополнительные include-каталоги,
  опции generator, проверка версии 0.24.0 и повторный цикл через обратный генератор.
- Негативные тесты генерации Java: неверный IDL, конфликт имён классов,
  существующий output без `--force`, symlink в выходном пути; ошибка до записи результата.

## Не выполнено

- Docker build/run и `docker compose config`: Docker в среде проверки отсутствует.
  Поэтому работоспособность именно контейнерной сборки/запуска пока не подтверждена.
- Java compilation, запуск клиента/сервера и сравнение сетевых сообщений.
- Проверка всех версий и всех режимов Apache Thrift Java generator.
